# Contributing to tint.zig

Thank you for your interest in contributing to tint.zig!

## Requirements

- Zig 0.16.0 or later
- No external dependencies

## Development

### Building

```bash
zig build
```

### Running Tests

```bash
zig build test
```

### Formatting

```bash
zig fmt src/ examples/
```

### Running Examples

```bash
zig build run-basic
zig build run-complete
```

## Code Quality

- Follow existing code style
- Add tests for new features
- Update documentation as needed
- Keep the library zero-dependency

## Pull Requests

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests and formatting
5. Submit a pull request

## Issues

Report issues at [GitHub Issues](https://github.com/muhammad-fiaz/tint.zig/issues).
